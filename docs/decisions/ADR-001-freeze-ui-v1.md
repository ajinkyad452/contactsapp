# ADR-001: Freeze VoiceDeck UI v1.0

- Status: Accepted
- Date: 2026-11-01

## Decision
Keep the voice-first entry flow and two-sided contact card as the design baseline.

The front contains a large photo, bold name, primary mobile number, and exactly two side-by-side actions: Call and WhatsApp. Previous / Next controls are used for navigation. Swipe gestures are not part of the baseline.

The back contains available contact details and an explicit route back to the front, plus Open in Google Contacts.

## Rationale
A predictable interface with visible controls is easier to learn and use for the target audience, including older adults.

## Consequences
New UI changes require explicit product approval and should preserve the frozen baseline unless the user asks to revise it.
