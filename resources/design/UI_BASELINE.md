# UI Baseline

The frozen VoiceDeck UI v1.0 is documented in `../../docs/UI_SPEC.md`.

Reference checklist:
- Voice-first launch.
- One contact card at a time.
- Front: photo, name, primary number, exactly Call and WhatsApp actions.
- Previous / Next navigation; no swipe.
- Back: saved details and Open in Google Contacts.
- Clean white, rounded-card presentation.
- Large, legible labels and simple controls.

Add approved design exports in this folder. Do not treat this text file as a pixel-perfect mock-up.
